# Лабораторная работа 1. Первые программы на Python

## Как запустить
Убедитесь, что установлен Python 3.13+. Откройте терминал в папке с файлами и запускайте:
`python profile.py`, `python workload.py`, `python debug.py`, `python swap.py`, `python variant.py`.

---

## Результаты проверок

### 1. `profile.py`
* **Вход:** Иванов, Иван, ИС-21, Москва, 17, Математика, 10.5
* **Ожидаемый результат:** Возраст через 4 года: 21. За 4 недели: 42.00 ч. В день: 1.50 ч.
* **Фактический результат:** Совпадает.
* **Граничный случай:** Часы = 0. Ожидается 0.00 и 0.00. Совпадает.

### 2. `workload.py`
* **Вход:** Математика, 3 занятия по 90 мин; Физика, 2 занятия по 45 мин; Доступно 10 часов.
* **Ожидаемый результат:** 270 и 90 мин, всего 360 мин (6.00 ч), остаток 4.00 ч, за 4 недели 24.00 ч.
* **Фактический результат:** Совпадает.
* **Граничный случай:** 0 занятий по обоим предметам. Нагрузка 0, остаток равен доступному времени. Совпадает.

### 3. `debug.py`
* **Результаты:** Сумма: 5, Возраст через год: 18, Среднее: 7.0.
* **Объяснение:** 
  * А: исправлено приведение строк к `int`.
  * Б: исправлено приведение `input()` к `int`.
  * В: исправлен приоритет операций (сумма в скобках).

### 4. `swap.py`
* **Вход:** А-101, Б-202
* **Ожидаемый результат:** А-101 и Б-202 меняются местами.
* **Фактический результат:** Совпадает. Временная переменная `temp` хранит первое значение.

### 5. `variant.py` (Вариант 1)
* **Вход:** Канцелярия, Иван, Тетради (3 шт. по 12.50), Ручки (2 шт. по 20.00), доставка 10.00, внесено 100.00.
* **Ожидаемый результат:** Тетради 37.50, Ручки 40.00, товары 77.50, всего 87.50, количество 5, сдача 12.50.
* **Фактический результат:** Совпадает.
* **Граничные случаи:** 
  * Нулевое количество одной позиции (стоимость 0.00). Совпадает.
  * Нулевая доставка. Совпадает.
  * Точная оплата без сдачи (сдача 0.00). Совпадает.
